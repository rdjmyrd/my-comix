# Путешествие Бена — онлайн-читалка

Откройте `index.html` в браузере. Комикс показывает одну страницу за раз: используйте стрелки по бокам, кнопки «Назад»/«Далее», точки под панелью или клавиши ← и →. На телефоне можно перелистывать страницы свайпом.

## Озвучка

Озвучка сохранена на основе встроенного синтеза речи браузера: для каждой страницы предусмотрены реплики Бена и диктора. Нажмите ▶, чтобы прослушать текущую страницу, и «Стоп», чтобы остановить. Доступность и звучание русских голосов зависят от браузера и устройства. Для работы озвучки требуется поддержка `SpeechSynthesis`.

Все исходные иллюстрации сохранены в `assets/pages/`.
